# 01. コンセプト

> **本作はアニメ映画『超かぐや姫！』の非公式ファン制作です。**
> キャラクター・世界観の権利は原作の権利者に帰属します。非営利・非公式。
> 原作に存在しない要素（敵、ステージ構成、強化システム、数値）は本作独自の追加です。
> [原作／独自の切り分け](./04-content.md#原作と本作独自要素の切り分け) と
> [出典・未確認事項](./04-content.md#出典) を参照。

## 1.1 ログライン

> 1 億人が集う仮想空間 **ツクヨミ**。そのライブ会場を、**歌い、踊り、魅せる**ことで守り抜く。
> かぐや・彩葉・ヤチヨの 3 人で、最後の 1 曲を歌い切れ。

## 1.2 世界観

舞台は原作と同じ、近未来の巨大メタバース **ツクヨミ**。

- ツクヨミは 1 億人超が利用する仮想空間。和風建築にネオンを重ねた街並みで、
  ライブ会場やバトルゲームのフィールドなど、多様なワールドを内包する。
- プレイヤーはかぐやたちのライブを支える立場で、
  ステージ上のポジション（＝配置マス）にメンバーを立たせ、セットリストを組んでライブを完走させる。
- 立ちはだかるのは、ツクヨミに湧く **ノイズ** —— 熱を吸い取り、ライブを止めようとする存在。
  **これは本作独自の設定**で、原作の登場人物・勢力ではない。
- ライブを完走している限りノイズは会場を侵食できない。
  歌・ダンス・ヴィジュアルが、ステージを守る唯一の手段。

トーンは原作のツクヨミに合わせた **和 × ネオン**。伝統的な意匠を蛍光色で塗り替えた過剰さを狙う。

## 1.3 体験の 3 本柱

| 柱 | 何を感じてほしいか | 実現する仕組み |
|---|---|---|
| **魅せて勝つ** | 攻撃が「攻撃」でなく「パフォーマンス」に見える | 歌 = 音波リング、ダンス = 残像ステップ、ヴィジュアル = 光の帯／カットイン |
| **盛り上がりの波** | 曲が進むほど画面が派手になる高揚感 | ウェーブ = 楽曲構成（イントロ→A→B→サビ）、サビで月華の蓄積と演出が加速 |
| **育てた分だけ強い** | 昨日の自分より強くなった実感 | ラン内 6 系統 + 恒久 4 系統の強化（[03](./03-progression.md)） |

## 1.4 コアループ

### バトル内ループ（1 ライブ ≒ 5〜8 分）

```
編成・ステージ選択
        ↓
  ライブ開始（イントロ）
        ↓
 ┌→ 声援(Cheer)を稼ぐ ─→ ポジションにメンバー配置 / 強化
 │        ↓
 │   ノイズのウェーブを迎撃 ─→ 月華ゲージ蓄積
 │        ↓
 │   ◆ でセットリスト強化を 3 択から 1 つ選ぶ
 │        ↓
 └── サビ: 月華を解放 = スペシャルライブ
        ↓
   完走 → リザルト（観客残量でランク S/A/B/C）
```

### メタループ（1 セッション ≒ 20〜40 分）

```
リザルト報酬（資金）
        ↓
レッスンでレベルアップ / 才能ボード / 衣装
        ↓
より高難度のステージ、または同ステージの★上げに再挑戦
        ↓
プロデューサーランク上昇 → 新ステージ解放
```

## 1.5 想定プレイヤー

- 原作『超かぐや姫！』のファン
- タワーディフェンス経験者（配置・射程・DPS の概念を理解している）
- キャラ育成・ビルド構築が好きな層（「強化要素が満載」が刺さる層）
- 1 プレイ 5〜8 分で区切れるため、短時間プレイと長時間周回の両方に対応

## 1.6 スコープ方針

「強化要素が満載」は本作の核だが、全系統を初手で作ると破綻する。
**縦に薄く全部作る** のではなく、**MVP を絞って面白さを確定させてから横に広げる**。
系統ごとの実装フェーズは [07. ロードマップ](./07-roadmap.md) に定義する。

- **MVP に含めるもの**: ポジション強化 / 覚醒分岐 / セットリスト / アイドルレベル / 簡易月華
- **MVP に含めないもの**: 衣装、才能ボード、フォーメーション、センター、コール
- **判断保留**（リリース後に実測してから決める）: スタジオ設備、還月（プレステージ）

「満載感」はメニューの数ではなく、**1 プレイ中の有意味な選択の回数・組み合わせ・
見た目の変化**から作る。同じ加算プールに小さな数値を複数の画面から供給するのは
重複であり、どれも実感を生まない（[03](./03-progression.md#戦力に効く系統とそうでない系統を分ける)）。
