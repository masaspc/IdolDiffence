# 01. コンセプト

## 1.1 ログライン

> 客席の熱が奪われていく世界で、少女たちは**歌い、踊り、魅せる**ことでしか戦えない。
> ステージに押し寄せる「サイレンス」を退け、最後の 1 曲を歌い切れ。

## 1.2 世界観

- 舞台は近未来のライブシティ。人々の「熱狂」がエネルギーとして流通している。
- 敵対存在 **サイレンス**（無関心・野次・虚飾が実体化したもの）が会場に侵入し、
  観客の熱を吸い取ってライブを中断させようとする。
- アイドルのパフォーマンスはサイレンスに直接ダメージを与えられる唯一の手段。
- プレイヤーは **プロデューサー**。ステージ上のポジション（＝配置マス）にメンバーを立たせ、
  セットリストを組み立ててライブを完走させる。

トーンは「熱血 × きらきら」。シリアス寄りの設定を、明るい演出とテンポで包む。

## 1.3 体験の 3 本柱

| 柱 | 何を感じてほしいか | 実現する仕組み |
|---|---|---|
| **魅せて勝つ** | 攻撃が「攻撃」でなく「パフォーマンス」に見える | 歌 = 音波リング、ダンス = 残像ステップ、ヴィジュアル = ハート弾／カットイン |
| **盛り上がりの波** | 曲が進むほど画面が派手になる高揚感 | ウェーブ = 楽曲構成（イントロ→A→B→サビ）、サビでボルテージ倍率と演出強化 |
| **育てた分だけ強い** | 昨日の自分より強くなった実感 | ラン内 6 系統 + 恒久 9 系統の強化（[03](./03-progression.md)） |

## 1.4 コアループ

### バトル内ループ（1 ライブ ≒ 5〜8 分）

```
編成・セットリスト選択
        ↓
  ライブ開始（イントロ）
        ↓
 ┌→ 声援(Cheer)を稼ぐ ─→ ポジションにメンバー配置 / レベルアップ
 │        ↓
 │   敵ウェーブ迎撃 ─→ ボルテージ蓄積
 │        ↓
 │   ウェーブ間: セットリスト強化を 3 択から 1 つ選ぶ
 │        ↓
 └── サビウェーブ: ボルテージ解放 = スペシャルライブ演出
        ↓
   完走 → リザルト（観客残量でランク S/A/B/C）
```

### メタループ（1 セッション ≒ 20〜40 分）

```
リザルト報酬（経験値・素材・衣装・チケット）
        ↓
アイドル育成 / 才能ボード / 衣装強化 / 施設アップグレード
        ↓
より高難度のステージ、または同ステージの★上げに再挑戦
        ↓
プロデューサーランク上昇 → 新ステージ・新アイドル解放
        ↓
（終盤）プレステージ「再デビュー」で永続ボーナスを得て周回
```

## 1.5 想定プレイヤー

- タワーディフェンス経験者（配置・射程・DPS の概念を理解している）
- キャラ育成・ビルド構築が好きな層（「強化要素が満載」が刺さる層）
- 1 プレイ 5〜8 分で区切れるため、短時間プレイと長時間周回の両方に対応

## 1.6 スコープ方針

「強化要素が満載」は本作の核だが、初手で全 15 系統を作ると破綻する。
**縦に薄く全部作る** のではなく、**MVP で 4 系統に絞って面白さを確定させてから横に広げる**。
系統ごとの実装フェーズは [07. ロードマップ](./07-roadmap.md) に定義する。

MVP に含めるもの: ポジション強化 / セットリスト / アイドルレベル / 衣装（1 スロットのみ）。
MVP に含めないもの: プレステージ、施設、絆、実績バフ、覚醒分岐。
