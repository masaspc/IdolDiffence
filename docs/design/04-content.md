# 04. コンテンツ設計

すべてオリジナル設定。既存作品のキャラクター名・楽曲名・意匠は使用しない。

### 敵の設計意図

各敵は **特定の強化・編成に対する問い** になっている。

| 敵 | 問い | 想定される答え |
|---|---|---|
| e_armor | 高 DEF をどう抜く？ | DEF 無視覚醒、Break デバフ、ヴィジュアル編成 |
| e_flyer | 経路外の脅威にどう備える？ | 対空持ちの配置、センターステージ近くの保険 |
| e_healer | 火力の集中をどうする？ | ターゲティング「最大 HP」、単体高火力のダンス |
| e_swarm / e_splitter | 手数不足をどう補う？ | 歌の範囲攻撃、Echo スタック |
| e_drainer | 攻撃速度デバフへの対処 | 熱狂バフ、スペシャル発動タイミングの調整 |

## 4.4 楽曲

楽曲はステージの BGM であり、同時に **編成にセットするアクティブスキル枠**（[03 ⑩](./03-progression.md#⑩楽曲レベル)）。

| 楽曲 | BPM | 構成 | アクティブ効果（Lv1） | CT |
|---|---|---|---|---|
| キラメキ・スターター | 132 | I-A-B-C-間-A-B-C-大 | 声援 +150 | 50s |
| ネオン・ステップ | 148 | I-A-B-C-間-B-C-大 | 全体攻撃速度 +30%（10s） | 60s |
| サイレント・クライ | 118 | I-A-A-B-C-間-C-大 | 全体に Break -40（8s） | 70s |
| オーバードライヴ | 172 | I-B-C-間-C-C-大 | ボルテージ +40 | 90s |
| ラスト・アンコール | 140 | I-A-B-C-間-A-B-C-C-大 | 全体 ATK +50%（8s） | 100s |

（I = イントロ、A = A メロ、B = B メロ、C = サビ、間 = 間奏、大 = 大サビ）

音源は権利上の理由から、初期は **手続き的に生成した BGM**（Web Audio API のシンセ）で代替し、
BPM とセクション境界だけを正確に持つ。差し替え可能な構造にしておく。

## 4.5 アートディレクション

- **画風**: アニメ調セルルック。太めの主線、影 2 段。彩度高め。
- **キャラ表示**: 戦闘中はデフォルメ 2 頭身のスプライト（64×64、8 方向不要・左右反転のみ）。
  編成・リザルト画面のみ等身大の立ち絵。
- **エフェクト優先**: キャラの描き込みより、エフェクト（音波リング、リボン、ハート、譜面）に予算を割く。
  タワーディフェンスは俯瞰視点でキャラが小さいので、**光と動きで気持ちよさを作る**方が費用対効果が高い。
- **暫定アセット**: 実装初期は色付きの円 + 系統アイコンで代替し、ゲームプレイの検証を先行させる。
- **カラーコード**: 歌 = `#FF6BA8`（ピンク）、ダンス = `#4FC3F7`（シアン）、ヴィジュアル = `#FFD54F`（ゴールド）。
  敵は属性ごとに 静寂 = `#7E57C2`、喧噪 = `#EF5350`、虚飾 = `#26A69A`。
