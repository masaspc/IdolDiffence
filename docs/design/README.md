## 3 行サマリ

- **ジャンル**: 固定ルート型タワーディフェンス + ローグライト + 育成 RPG（シングルプレイ / Web）
- **売り**: 攻撃手段が「歌 = 範囲・持続」「ダンス = 単体・機動」「ヴィジュアル = 妨害・支援」の 3 系統に分かれ、
  ライブが進むほど **月華ゲージ（ボルテージ）** が溜まり、サビで一斉に必殺演出が炸裂する
- **強化**: 1 プレイ内で完結する強化（セットリスト / 覚醒分岐 / フォーメーション）と、
  プレイをまたいで積み上がる強化（レベル / 才能ボード / 衣装 / 施設 / 還月）の二層構造

**メインキャラクター**: 竹取 かぐや（ヴィジュアル）/ 千歳 やちよ（歌）/ 東雲 いろは（ダンス）

## 設計上の前提

- シングルプレイ、オフライン動作、課金なし（「スカウト」はゲーム内通貨のみ）
- ブラウザ（PC / タブレット）想定、60fps、初回ロード 5MB 以内を目標
- キャラクター・楽曲・敵はすべてオリジナル。既存作品の意匠・固有名詞は使用しない
- 数値は `data/*.json` で外出しし、コード変更なしでバランス調整できること
