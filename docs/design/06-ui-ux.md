# 06. UI / UX

## 6.1 画面遷移

```
タイトル
  └→ ホーム
       ├→ ライブ選択（ステージ / ★難度）→ 編成 → バトル → リザルト → ホーム
       ├→ アイドル育成（レベル / 限界突破 / スキル / 才能ボード）
       ├→ 衣装（装備 / 強化 / 錬成）
       ├→ ユニット（絆の会話 / コレクション）
       ├→ 実績 / 称号
       └→ 設定
```

実装（M5-1 後）。ホームは**入口だけ**を並べ、中身はそれぞれの画面に置く。

```
ホーム（編成 / 才能ボード / 衣装 / 称号・実績 / 育成 / ライブ / ⚙設定）
  ├→ 編成      … 5 人を選び、1 人をセンターに
  ├→ 才能ボード
  ├→ 衣装      … 装備 / 強化 / 錬成
  ├→ 称号・実績
  ├→ 育成      … 左にメンバー一覧、右に**能力の詳細**とレッスン・進化
  └→ 設定      … コール / 演出強度 / 文字サイズ / 属性の記号
```

### 育成画面（キャラクターの詳細）

**ホームの「レッスン」から分けた。** 元は名前・攻撃力・ボタンしか出しておらず、
**そのキャラが何をするのかがどこにも書いていなかった**。覚醒 A と B のどちらを
選ぶか、センターを誰にするか、進化で何が変わるか —— どれも決めるのに要る情報が
画面に無く、`idols.json` を読まないと分からない状態だった。

出すもの: 系統と有利な属性 / 攻撃の形（範囲・貫通・対空・防御無視・命中時効果）/
オーラ / 名指しの相性 / センターパッシブ / 覚醒 A・B の中身 / 着ている衣装 /
レッスンの費用 / 進化の条件と効果。

**文言は数値から導く**（`src/ui/idolText.ts`）。JSON に説明文を書き足すと、
数値を変えたときに文だけ古いまま残る（衣装の実効値・ランクと同じ罠）。
DOM に触らない層に置いてあるので、文言そのものをテストで固定できる。

書き方で決めていること:

- **倍率は 1 との差で書く。** 「×1.8」ではなく「+80%」。画面のなかで
  加算と乗算が混ざるので、読む側の単位をそろえる
- **攻撃間隔は速いか遅いかを言い添える。** 「×0.6」だけでは、
  速くなるのか遅くなるのかが読めない
- **進化を解放していれば進化後の値で書く。** 攻撃力だけ進化後で
  範囲は素のまま、では画面のなかで食い違う
- **相性の相手は名前で出す。** `V1` ではなく「かぐや」

### 隠しキャラの登場

解放しただけでは気づかれない。ホームの「育成」タブが 12 → 13 に増えるだけでは、
**ゲームでいちばん強い駒が黙って増える**ことになる。

ホームの最上段に専用のカードを出す（`.secret-reveal`）。他のお知らせと色を分けてあるのは、
「前回のライブ」や「才能ポイント 3 pt」と同じ見た目にすると、お知らせ 1 件に埋もれるから。
押すとその人の詳細が開き、以後は二度と出ない。

**「見せたかどうか」だけはセーブに持つ**（`save.seenSecrets`）。解放そのものは
`bestStar` から導けるが、知らせたかどうかは出来事で、進捗からは復元できない。
持たないとホームを開くたびに同じ通知が出続ける。合言葉で開いたときも同じカードが出る ——
打った本人は知っているが、何も起きないと入力が通ったのか分からない。

- ホームは「次に何をすればいいか」が一目で分かることを最優先にする。
  強化系統が多いため、**未消化のリソース（振れる才能ポイント、強化可能な衣装、
  レベル上限に達していないキャラ）にバッジを出す**。強化の入口が多いゲームでは、これがないと確実に迷子になる。

## 6.2 バトル画面 HUD

```
┌──────────────────────────────────────────────────────┐
│ 観客 ████████████░░ 82   ♪ 月光サイレンス  [Bメロ 2/3]     │ ← 上部バー
├──────────────────────────────────────────────────────┤
│                                                      │
│                  【 ステージ（Canvas）】                │
│                                                      │
│                                        [ウェーブ先読み]│ ← 右上
├──────────────────────────────────────────────────────┤
│ 声援 ♥ 340   VOLTAGE ███████░░░ 71%  [SPECIAL]        │ ← 下部バー
│ [かぐや30][彩葉25][ヤチヨ35][照琴60][芦花80] ⏩ 速度 x2 │ ← 配置パレット（編成の 5 人）
└──────────────────────────────────────────────────────┘
       ↑ サビ中はここにコールマーカーが流れる
```

- **配置**: パレットからドラッグ＆ドロップ、またはタップ→配置マスをタップ。
  ドラッグ中は射程円と、成立するフォーメーションボーナスをプレビュー表示。
- **ユニット選択**: クリックで詳細ポップオーバー（レベルアップ / 覚醒 / ターゲティング / 売却）。
- **速度**: 1x / 2x / 3x。3x はステージクリア済みのみ解放（周回配慮）。
- **一時停止**: `P` キー。一時停止中も配置・強化の操作を許可する（戦略ゲームとして親切に）。
  サビ中は `Space` がコール入力に使われるため、一時停止には割り当てない
  （文脈で意味が変わるキーは、押した瞬間に何が起きるか予測できないので避ける）。

## 6.3 情報設計の原則

強化要素が多いゲームで最も壊れやすいのは「何が効いているか分からない」状態。以下を徹底する。

1. **数値の出自を必ず表示する**
   ユニット詳細に「ATK 1,240」だけでなく、内訳を展開表示:
   ```
   ATK 1,240
     基礎 90 × Lv42 (×3.46)  = 311
     限界突破 ★4              ×1.24
     衣装（+ATK% 合計 86%）    ×1.86
     才能ボード                ×1.31
     フォーメーション（同系統） ×1.12
     ポジション Lv3            ×2.10   ← ラン内
   ```
2. **相性を色で即伝達**。ダメージポップアップを 有利=大きく黄色 / 不利=小さく灰色 にする。
3. **ウェーブ先読み**。次ウェーブの敵構成と属性を上部に常時表示し、事前対応を可能にする。
4. **リザルトで貢献度を可視化**。系統別・キャラ別のダメージ寄与を円グラフで出し、
   「誰を育てるべきか」の判断材料にする。

## 6.4 演出

| タイミング | 演出 |
|---|---|
| サビ突入 | 画面外周に光のリング、背景の観客ペンライトが一斉に色替え |
| スペシャルライブ | 0.4 秒のカットイン（センターの立ち絵）→ 画面全体にダメージ波 → 8 秒間の高彩度モード |
| 覚醒（Lv3） | ユニットが一瞬光り、衣装スプライトが差し替わる + 専用ボイス |
| Perfect コール | ペンライトの波が画面下から立ち上がる |
| 観客ゲージ 20% 以下 | 画面周辺が暗くなり、BGM のハイパスフィルタが強まる（緊迫感） |
| 敵の出現 | ステージ奥に光の柱が降り、そこからノイズが湧き出す |
| 強制ログアウト（B2） | 対象レーンにノイズの帯が走り、そのレーンのメンバーの色が抜ける（沈黙の可視化） |
| ライブ完走 | ノイズが晴れ、背景が夜明けの色に変わる |

演出は **スキップ可能** かつ **設定で簡略化可能** にする（周回時のストレス回避 + 低スペック対応）。

### カットイン（`src/render/cutin.ts`）

**盤面から目を離させる演出には、その価値がないといけない。**
カットインは画面の半分を 1 秒前後ふさぐので、
「見逃すと立て直しが利かない」場面にだけ出す。

| 種類 | 出るとき | 顔 | 色 |
|---|---|---|---|
| `special` | 月華の解放 | センター | 桃 → 金 |
| `solo` | ソロパートの発動 | 撃つ本人 | 緑 → 空 |
| `boss` | ボスの登場 | **その敵** | 紫 → 赤 |
| `phase` | ボスの属性が変わった | なし | 紺 → 藤 |
| `danger` | 観客が 25 以下になった | なし | 赤 → 橙 |

撃破・配置・強化のような**毎秒起きること**には出さない（音のほうで返す）。

- **敵側は味方と違う色にする。** 同じ色だと「良いことが起きた」のか
  「まずいことが起きた」のかが一瞬で読めない
- **溜めない。** ボスが 2 体同時に湧くような場面ではきっかけが一度に来る。
  列を作ると、盤面が動いているのに数秒遅れの通知が流れ続けることになるので、
  **同じ種類は上書き、違う種類は 1 つだけ控える**
- **フェーズ変化は「何が変わったか」を名指しする。** 「フェーズ 2」では
  編成のどこを直せばいいのか分からない。属性名を出す
- **危機の警告は 1 回だけ。** 境目を行き来するたびに出すと、
  いちばん忙しい場面でカットインが連発する
- **最小設定でも消さない。** これは点滅ではなく**情報**で、消すと
  「ボスが湧いたことに気づかない」が起きる。長さだけを 0.6 倍にして刺激を落とす
  （閃光の側は `flashAmount` で別に落ちる）
- 時間は **sim ではなく描画側**で数える。sim 時刻に紐付けると、
  一時停止で演出が固まり、倍速で早送りされる

顔は**盤面と同じドット絵**をそのまま大きく描いている。立ち絵を別に用意すると
枚数が増えるうえ、盤面の絵と別人に見える。

## 6.5 オンボーディング

強化系統を一度に全部見せない。段階解放で認知負荷を制御する（`meta/onboarding.ts`）。

| 解放タイミング | 開く要素 |
|---|---|
| ステージ 1 | 配置、ポジション強化 |
| ステージ 1 クリア | **セットリスト**、編成 |
| ステージ 2 クリア | **ボルテージ / 月華解放**、育成（レベル・進化） |
| ステージ 5 クリア | フォーメーション表示、才能ボード |
| ステージ 7 クリア | **衣装（4 スロット + セット効果）**、センター選択 |
| ステージ 10 クリア | ★難度、楽曲レベル、称号・実績 |

**順番は設計ではなく実測で決めた。** 当初の表は「セットリストは S2 クリア、
月華は S3 クリア」だったが、ヘッドレスで測ると **S3 は月華が無いと勝てない**
（Lv5・フル配置で月華ありは 5 seed 中 3 勝、無しは 1 勝）。表のとおりに塞ぐと、
ちょうど難しくなる回で最も強い手札を取り上げることになっていた。

逆に **S1 と S2 は両方塞いでも 5/5 で勝てる**（フル配置なら観客 100）ので、
1 本ずつ前倒しした。「1 ステージにつき新しい仕組みは 1 つ」という意図はそのまま、
難度の実測とも合う ——

- **S1** 配置と強化だけ
- **S2** セットリストが増える
- **S3** 月華が増える（ここから難しくなる）

**覚醒分岐は塞がない。** ポジション Lv3 に届いたその場で選ぶものなので、
出てきた瞬間に説明すれば足りる（下のチュートリアル）。塞ぐと参照盤面の
`awakening` が効かなくなり、S1〜S3 の難度を測り直すことになる。

### 解放状態はセーブに持たない

ステージ進捗から毎回導く。実績・才能ポイントと同じ方針で、保存すると
解放条件を変えたときに**古いセーブだけが食い違う**（05-architecture.md 5.7）。

sim へは「まだ開いていない要素」だけを `BattleMeta.locked` で渡す。
**省略すると全部使える** —— ヘッドレス計測もテストも「全部ある盤面」が基準で、
既定で塞ぐと hpMul の実測が全部やり直しになる。

### 隠すだけでは進行が止まったように見える

見えないものがあること自体は伝える。ホームの下に 1 行だけ
「◯◯（S5）をクリアすると **才能ボード** が開きます」を出し、
リザルトの直後には「新しく開きました」を出す ——
ホームへ戻ってから自分で探させると気づかれない。

**設定だけは何があっても塞がない。** アクセシビリティの設定を進行の後ろに置くと、
それが必要な人が最初のライブを越えられない。

## 6.5b チュートリアル

**遊ぶ前にルールをまとめて読ませる形は取らない。** 読み飛ばされるし、読んでも
まだ画面に無いものの話なので身に付かない。代わりに「その操作が初めて要る瞬間」に
1 枚だけ札を出す（`meta/tutorial.ts`）。

| 札 | 出るとき | 指す先 |
|---|---|---|
| まずは配置 | まだ 1 体も置いていない | パレット |
| 置いた人を強化する | 1 体でも置いた | ユニットパネル |
| いまライブは止まっています | ◆ が出た | セットリスト |
| 月華解放 | ボルテージが満タンになった | 月華ゲージ |
| 覚醒分岐 | ポジション Lv3 に届いた | ユニットパネル |
| 通すと観客が減る | 初めて漏らした | 観客ゲージ |

- **一度に出るのは 1 枚だけ。** 最初のライブは「配置 → 強化 → 漏れ」が
  数秒のうちに続けて起きるので、並べて出すと画面が札で埋まる
- **選択中の札は割り込む。** ◆ が出ているあいだは他の操作ができない。
  そこで「強化しましょう」を出しても押せるものが無い
- **盤面を覆わない。** 全画面のモーダルにすると、説明しているものが
  説明のあいだだけ見えなくなる。指す先の近くに小さく貼る
- **自動で消さない。** 読む前に消えたとき、戻す手段が無い
- **札は画面のいちばん上に置く。** 下部バーの中に置いていたら、
  セットリストの選択（全画面のオーバーレイ）に覆われて「わかった」が押せなかった
  —— よりによって、そのオーバーレイを説明する札が押せない状態になっていた
- **演出「控えめ」でも消さない。** これは点滅ではなく情報で、
  消すと遊び方が分からないまま進むことになる（6.7）
- **もう一度見られる。** 一度きりの説明は必ず読み逃されるので、
  設定から出し直せるようにしてある

見せたかどうかは**セーブに持つ**（解放状態と違って、これは出来事で進捗からは
復元できない）。すでに 1 本でもクリアしているセーブには出さない ——
配置も強化もセットリストも通ってきた人に、いまさら「まずは配置」は失礼なうえ邪魔になる。

## 6.6 操作 / 入力

| 操作 | マウス | キーボード | タッチ |
|---|---|---|---|
| 配置 | ドラッグ&ドロップ | 1-5 で選択 → 方向キー + Enter | タップ→タップ |
| 一時停止 | ボタン | `P` | ボタン |
| 速度変更 | ボタン | `Tab` | ボタン |
| コール | クリック | `Space` / `F` | 画面下部タップ |
| スペシャル発動 | ボタン | `Q` | ボタン |
| 楽曲アクティブ | ボタン | `E` | ボタン |
| メニュー / キャンセル | — | `Esc` | ボタン |

**キー割り当ての原則**: 1 つのキーに文脈依存の複数機能を持たせない。
特に `Space` はコール専用とし、一時停止（`P`）とは明確に分離する。
コール入力を OFF にしている場合も `Space` は一時停止に転用せず、未割り当てのままにする
（設定によって同じキーの意味が変わるのを避けるため）。全キーはリバインド可能。

## 6.7 アクセシビリティ

- **色覚**: 系統は色に加えて必ず形アイコン（♪ / ★ / ♥）を併記する。
- **コール OFF**: リズム操作を完全に無効化できる。無効時は自動で Good 相当の補正を付与し、
  プレイヤー間の有利不利を実質ゼロにする。
- **演出強度**: 「標準 / 控えめ / 最小」の 3 段階。点滅・画面揺れの抑制を含む（光過敏対策）。
- **文字サイズ**: 100% / 125% / 150%。HUD は rem ベースでレイアウトする。
- **フルキーボード操作**に対応（マウス必須にしない）。
- **音無しでプレイ可能**。BPM 同期の視覚表現（ペンライトの点滅）を音の代替にする。

**実装（M5-1、`src/meta/settings.ts` と設定画面）。**

| 設定 | 既定 | 効くところ |
|---|---|---|
| コール | **オフ**（自動 Good） | `BattleMeta.call`。切っていると小節ごとに Good が自動で入る |
| 演出強度 | 標準 | `flashCount` で拍の点滅とスペシャルの閃光を弱める／止める。最小では浮遊ダメージ表示と CSS のアニメーションも止まる |
| 文字サイズ | 100% | 根の `font-size`。HUD も画面も rem なので 1 か所で通る |
| 敵に属性の記号 | オフ | 敵の中央に ○△□ を重ねる。色だけで見分けさせない選択肢 |

判断がふたつ。

- **既定は「誰でも遊べる側」に倒す。** 設定画面を開かないまま遊ぶ人がいちばん多い、
  という前提で決めている。初回起動でいきなり点滅が走り、
  リズム入力を要求される状態にはしない
- **演出強度は情報を落とさない。** 「控えめ」で消すのは光の刺激だけで、
  敵・射程・配置マスの描き方は 3 段階とも同じ。
  浮遊ダメージ表示を止めるのは「最小」だけにしてある
- 系統の形アイコン（♪ ★ ♥）は**設定に関わらず常に**出す。
  これは選べる項目ではなく、色覚の前提として動かさない

**演出強度は「出す / 出さない」ではなく振れ幅で効かせる。**
最初 `flashAmount` を 0 かどうかの門にしか使っておらず、「控えめ」を選んだ人に
標準とまったく同じ閃光が出ていた。閃光・輪・カットインの不透明度すべてに掛けている。

**Space は盤面にフォーカスがあるときだけコールへ回す。**
ボタンにフォーカスがある状態の Space は「そのボタンを押す」操作なので、
奪うとキーボードだけで遊ぶ人が一時停止もカード選択も押せなくなる。
