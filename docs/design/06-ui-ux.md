# 06. UI / UX

## 6.1 画面遷移

```
タイトル
  └→ ホーム
       ├→ ライブ選択（ステージ / ★難度）→ 編成 → バトル → リザルト → ホーム
       ├→ アイドル育成（レベル / 限界突破 / スキル / 才能ボード）
       ├→ 衣装（装備 / 強化 / 錬成）
       ├→ ユニット（絆の会話 / コレクション）
       ├→ 実績 / 称号
       └→ 設定
```

- ホームは「次に何をすればいいか」が一目で分かることを最優先にする。
  強化系統が多いため、**未消化のリソース（振れる才能ポイント、強化可能な衣装、
  レベル上限に達していないキャラ）にバッジを出す**。強化の入口が多いゲームでは、これがないと確実に迷子になる。

## 6.2 バトル画面 HUD

```
┌──────────────────────────────────────────────────────┐
│ 観客 ████████████░░ 82   ♪ 月光サイレンス  [Bメロ 2/3]     │ ← 上部バー
├──────────────────────────────────────────────────────┤
│                                                      │
│                  【 ステージ（Canvas）】                │
│                                                      │
│                                        [ウェーブ先読み]│ ← 右上
├──────────────────────────────────────────────────────┤
│ 声援 ♥ 340   VOLTAGE ███████░░░ 71%  [SPECIAL]        │ ← 下部バー
│ [かぐや30][彩葉25][ヤチヨ35][りん50][るり80] ⏩ 速度 x2 │ ← 配置パレット
└──────────────────────────────────────────────────────┘
       ↑ サビ中はここにコールマーカーが流れる
```

- **配置**: パレットからドラッグ＆ドロップ、またはタップ→配置マスをタップ。
  ドラッグ中は射程円と、成立するフォーメーションボーナスをプレビュー表示。
- **ユニット選択**: クリックで詳細ポップオーバー（レベルアップ / 覚醒 / ターゲティング / 売却）。
- **速度**: 1x / 2x / 3x。3x はステージクリア済みのみ解放（周回配慮）。
- **一時停止**: `P` キー。一時停止中も配置・強化の操作を許可する（戦略ゲームとして親切に）。
  サビ中は `Space` がコール入力に使われるため、一時停止には割り当てない
  （文脈で意味が変わるキーは、押した瞬間に何が起きるか予測できないので避ける）。

## 6.3 情報設計の原則

強化要素が多いゲームで最も壊れやすいのは「何が効いているか分からない」状態。以下を徹底する。

1. **数値の出自を必ず表示する**
   ユニット詳細に「ATK 1,240」だけでなく、内訳を展開表示:
   ```
   ATK 1,240
     基礎 90 × Lv42 (×3.46)  = 311
     限界突破 ★4              ×1.24
     衣装（+ATK% 合計 86%）    ×1.86
     才能ボード                ×1.31
     フォーメーション（同系統） ×1.12
     ポジション Lv3            ×2.10   ← ラン内
   ```
2. **相性を色で即伝達**。ダメージポップアップを 有利=大きく黄色 / 不利=小さく灰色 にする。
3. **ウェーブ先読み**。次ウェーブの敵構成と属性を上部に常時表示し、事前対応を可能にする。
4. **リザルトで貢献度を可視化**。系統別・キャラ別のダメージ寄与を円グラフで出し、
   「誰を育てるべきか」の判断材料にする。

## 6.4 演出

| タイミング | 演出 |
|---|---|
| サビ突入 | 画面外周に光のリング、背景の観客ペンライトが一斉に色替え |
| スペシャルライブ | 0.4 秒のカットイン（センターの立ち絵）→ 画面全体にダメージ波 → 8 秒間の高彩度モード |
| 覚醒（Lv3） | ユニットが一瞬光り、衣装スプライトが差し替わる + 専用ボイス |
| Perfect コール | ペンライトの波が画面下から立ち上がる |
| 観客ゲージ 20% 以下 | 画面周辺が暗くなり、BGM のハイパスフィルタが強まる（緊迫感） |
| 敵の出現 | ステージ奥に光の柱が降り、そこからノイズが湧き出す |
| 強制ログアウト（B2） | 対象レーンにノイズの帯が走り、そのレーンのメンバーの色が抜ける（沈黙の可視化） |
| ライブ完走 | ノイズが晴れ、背景が夜明けの色に変わる |

演出は **スキップ可能** かつ **設定で簡略化可能** にする（周回時のストレス回避 + 低スペック対応）。

## 6.5 オンボーディング

強化系統を一度に全部見せない。段階解放で認知負荷を制御する。

| 解放タイミング | 開く要素 |
|---|---|
| ステージ 1 | 配置、ポジション強化 |
| ステージ 2 クリア | セットリスト、アイドルレベル |
| ステージ 3 クリア | **覚醒分岐**、ボルテージ / スペシャル |
| ステージ 5 クリア | フォーメーション表示、才能ボード |
| ステージ 7 クリア | **衣装（4 スロット + セット効果）**、センター選択 |
| ステージ 10 クリア | ★難度、楽曲レベル、称号・実績 |

## 6.6 操作 / 入力

| 操作 | マウス | キーボード | タッチ |
|---|---|---|---|
| 配置 | ドラッグ&ドロップ | 1-5 で選択 → 方向キー + Enter | タップ→タップ |
| 一時停止 | ボタン | `P` | ボタン |
| 速度変更 | ボタン | `Tab` | ボタン |
| コール | クリック | `Space` / `F` | 画面下部タップ |
| スペシャル発動 | ボタン | `Q` | ボタン |
| 楽曲アクティブ | ボタン | `E` | ボタン |
| メニュー / キャンセル | — | `Esc` | ボタン |

**キー割り当ての原則**: 1 つのキーに文脈依存の複数機能を持たせない。
特に `Space` はコール専用とし、一時停止（`P`）とは明確に分離する。
コール入力を OFF にしている場合も `Space` は一時停止に転用せず、未割り当てのままにする
（設定によって同じキーの意味が変わるのを避けるため）。全キーはリバインド可能。

## 6.7 アクセシビリティ

- **色覚**: 系統は色に加えて必ず形アイコン（♪ / ★ / ♥）を併記する。
- **コール OFF**: リズム操作を完全に無効化できる。無効時は自動で Good 相当の補正を付与し、
  プレイヤー間の有利不利を実質ゼロにする。
- **演出強度**: 「標準 / 控えめ / 最小」の 3 段階。点滅・画面揺れの抑制を含む（光過敏対策）。
- **文字サイズ**: 100% / 125% / 150%。HUD は rem ベースでレイアウトする。
- **フルキーボード操作**に対応（マウス必須にしない）。
- **音無しでプレイ可能**。BPM 同期の視覚表現（ペンライトの点滅）を音の代替にする。
